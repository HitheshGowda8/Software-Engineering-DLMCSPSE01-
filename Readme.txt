Smart Inventory Management System
Project Overview

Smart Inventory Management System is a MERN Stack web application developed for small retail shops and grocery stores. The system helps shop owners manage products, inventory stock, suppliers, sales records, and sales reports through a simple and user-friendly dashboard.

Main Features

Product Management
Inventory Tracking
Low Stock Alerts
Sales Recording
Sales Reports
Supplier Management
Dashboard Analytics
Responsive User Interface
Technologies Used
React.js
Node.js
Express.js
MongoDB
CSS
Axios

How to Run the Project
Step 1: Extract ZIP File

Extract the project ZIP file on your computer.

Step 2: Install Backend Dependencies

Open terminal inside the backend folder:


npm install
Step 3: Setup Environment Variables

Create .env file inside backend folder and add:

PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/smart_inventory

Step 4: Run Backend Server

Inside backend folder:

npm run dev

Backend will run on:

http://localhost:5000

Step 5: Install Frontend Dependencies

Open terminal inside frontend folder:

npm install

Step 6: Run Frontend

Inside frontend folder:

npm run dev

Frontend will run on:

http://localhost:5173

Requirements
Node.js installed
MongoDB installed and running
Internet browser (Chrome recommended)
